# n8n development workflows

These templates keep business logic in the API. Configure HTTP Request nodes with an n8n credential containing `INTEGRATION_SERVICE_TOKEN`; never place the Gemini key or database URL in n8n.

Recommended workflow names:

- `shorts_create_project_dev`
- `shorts_generate_next_dev`
- `shorts_notify_prompt_ready_dev`
- `shorts_error_handler_dev`
